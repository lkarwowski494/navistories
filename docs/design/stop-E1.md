## Decyzja do podjęcia (produktowa)
Które 3 kierunki rozwinąć w E2?
- **(A) Drogowskaz + Rejestr + Pasmo** — trzy różne światy: znak drogowy, dokument instytucji, sprzęt audio. Kompromis: Pasmo niesie ryzyko kiczu retro.
- (B) Drogowskaz + Rejestr + Pikietaż — dwa kierunki z tego samego świata drogi; mniej rozbieżności; Pikietaż bez źródła.
- (C) Drogowskaz + Pasmo + Nakładka starej mapy — mapa w ruchu jest sprzeczna z P4; licencje map nieznane.

**Rekomendacja: A** — największa rozbieżność przy zachowaniu źródeł; każdy kierunek niesie inny rodzaj prawdziwych danych (odległość i strona drogi / źródła i rodzaj treści / km trasy).
